# Changelog

## 0.1.0 — 2026-11-02

Initial release.

- bounded embedded event stream with named fan-out subscriptions;
- explicit back-pressure and payload/resource budgets;
- Kafka producer with exact type/version routing and broker receipts;
- Kafka reader with consumer groups and explicit commit;
- CloudEvents-compatible Kafka binary metadata mapping;
- at-least-once semantics and stable event identity;
- design-assistance boundary for durable acceptance and downstream processing;
- interoperability, race, build and ARM64 evidence gates.
